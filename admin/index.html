Desde aquí se suben las galerías y las fotos. Solo hace falta entrar una vez en cada ordenador.

¿Cómo consigo la clave de acceso?
  1. Entra en GitHub con tu cuenta y ve a Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Pulsa Generate new token y ponle un nombre (por ejemplo "Panel de la web").
  3. En Expiration elige la fecha más lejana que permita (hasta 1 año).
  4. En Repository access elige Only select repositories y marca solo el repositorio de la web.
  5. En Permissions → Repository permissions pon Contents: Read and write.
  6. Pulsa Generate token, copia el texto que empieza por github_pat_ y pégalo arriba. Solo se muestra una vez.
